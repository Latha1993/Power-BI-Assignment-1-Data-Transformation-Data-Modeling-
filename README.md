**📊 Sales Data Transformation & Modeling | Power BI**

Transforming Raw Sales Data into Clean, Structured & Analysis-Ready Data

**📌 Project Overview**

This project focuses on cleaning, transforming, and modeling raw sales data using Microsoft Power BI and Power Query Editor.
Three CSV datasets were imported, cleaned, transformed, and combined to create a structured data model for future analysis and reporting.

**🛠️ Tools & Technologies**

Microsoft Power BI

Power Query Editor

CSV Files

**📂 Datasets**

**Dataset	Description**

List of Orders	Customer, order date, city, state, and sales details

Order Details	Category, sub-category, quantity, amount, and profit

Sales Target	Category, order month, and target amount


**⚙️ Data Transformation & Cleaning**

The following tasks were performed:

1.Imported three CSV datasets into Power BI.

2.Selected the first 500 rows from List of Orders.

3.Corrected column data types.

4.Applied Proper Case formatting to customer names.

5.Created a Location column using City and State.

6.Calculated Profit Margin.

7.Created a conditional Profit Status column (Profit, Loss, and Break-Even).

8.Merged order tables using Order ID.

9.Checked missing values and removed duplicates.

10.Sorted and filtered sales records.

11.Grouped data by Category and Sub-Category.

12.Calculated Order Count, Average Profit, and Total Amount.

13.Summarized monthly sales targets.

14.Created and verified table relationships.


**🔗 Data Modeling**

Established the following relationships in Power BI Model View:


Related Tables	Key Column
List of Orders → Order Details	Order ID
Order Details → Sales Target	Category
These relationships connect the datasets and provide a foundation for further analysis.
